# 🎬 Sentiment Analysis Web App

This project is a simple **Sentiment Analysis Web App** built using **Python**, **Scikit-learn**, and **Gradio**, and deployed on **Hugging Face Spaces**.  
It predicts whether a given movie review is **positive** or **negative** using a Support Vector Machine (SVM) classifier trained on textual data.

---

## 🚀 Live Demo

👉 **Try the App here:** [Deployed Link](https://huggingface.co/spaces/Tjsj275/Sentiment_Analysis)  

---

## 🧠 Features
- Interactive web interface built with **Gradio**
- Machine Learning pipeline with **TF-IDF Vectorizer + LinearSVC**
- Real-time sentiment prediction
- Deployed on **Hugging Face Spaces** for free & permanent hosting

---

## Model Details

- **Model Used:** LinearSVC (Support Vector Classifier)
- **Feature Extraction:** TfidfVectorizer
- **Dataset:** Custom CSV (movie_review.csv)
- **Metric:** Accuracy ≈ 85–90% (depends on data)
